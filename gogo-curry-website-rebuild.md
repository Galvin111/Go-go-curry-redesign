# Go Go Curry USA — Website Rebuild Spec

## Project Overview
Rebuild the Go Go Curry USA website with a clean, minimalist but strongly branded design. Final build will be implemented and hosted on **Squarespace**, so all layout, section, and component recommendations must be achievable using native Squarespace design tools (sections, blocks, summary blocks, galleries, forms) — avoid custom layouts that require heavy custom code injection unless noted as optional/stretch.

**Branches covered:** Times Square (NYC) and Cambridge (MA).

## Platform Requirements
- Must be buildable in Squarespace using standard section/block layout system (Fluid Engine compatible).
- Use Squarespace-native components wherever possible: Gallery blocks, Form blocks, Summary blocks, Button blocks, Accordion blocks.
- Avoid design patterns that rely on non-native code (parallax effects, complex JS interactions) — keep it achievable with Squarespace's built-in style editor.
- Fully responsive: every section needs a defined **desktop** and **mobile** treatment.

## Design Direction
- **Style:** Clean, minimalist, generous white space, modern grid layout — but unmistakably Go Go Curry branded (not generic).
- **Brand identity cues:** gorilla logo/mascot, "GoGo Yellow," bold high-contrast color blocking, energetic/"Genki" tone.
- **Typography:** one strong display/headline font for branding moments (bold, energetic) + one clean sans-serif for body copy/menus — both should be Squarespace-library fonts for easy setup.
- **Imagery:** food-forward photography (curry bowls, katsu, toppings), gorilla branding elements used as accents (icons, dividers, background watermark), customer photo content used generously.

## Brand Colors
Confirmed Go Go Curry palette:
- **Red** — `#BB0C26` — primary brand color (headers, CTAs, key accents)
- **Yellow** — `#FED503` — "GoGo Yellow," secondary/high-energy accent (buttons, highlights, gorilla branding moments)
- **Black** — `#000000` — text, high-contrast blocks, logo
- **White** — `#FFFFFF` — base/minimalist canvas

Use red and yellow as the dominant branded moments (hero, buttons, section dividers), black for text/contrast, and white as the clean minimalist backdrop that lets the branding pop rather than overwhelm.

## Page-by-Page Specs

### 1. Home
- Hero section: bold gorilla/branding visual + tagline, minimalist layout, high-impact photography of a signature curry dish.
- **Two prominent branch buttons front and center:** "Times Square" and "Cambridge" — styled as large, tappable buttons/cards so visitors can immediately jump to their nearest branch page.
- Brand story teaser section (short "Genki"/energy positioning blurb, can double up with or link to About).
- Featured menu highlights (3–4 signature dishes with photos).
- Customer photos preview strip (pulls into full gallery on its own section or links to a Customer Photos area).
- CTA banner for Order Online.
- Footer.

### 2. Menu
- Clean, minimalist menu layout (categories: Katsu Curry, Toppings, Sides, Drinks, Limited-Time, etc. — structure to match current offerings).
- Should be easy to update — Squarespace-friendly (structured text/blocks or summary block layout, not an embedded image-only menu, to keep it accessible and SEO-friendly). A downloadable/printable PDF version can also be linked.
- Photography per section where possible.

### 3. Times Square (branch page)
- Address, phone, hours.
- Embedded map.
- Branch-specific menu link (or note if menu is shared site-wide).
- **Customer photos section** specific to this branch.
- Order Online buttons (Pickup / DoorDash / Grubhub / etc.) specific to this branch.

### 4. Cambridge (branch page)
- Same structure as Times Square: address, phone, hours, map, customer photos, order online buttons for this branch's delivery/pickup links.

### 5. Order Online
- Central hub page with both branches listed.
- Clear buttons per branch, per platform: Pickup (direct), DoorDash, Grubhub, (and any others currently used).
- Minimal, scannable layout — this page's job is to get people to the right link fast.

### 6. Franchising
- Keep existing page/content as-is. No redesign changes needed — just carry it over into the new Squarespace site and restyle to match the new site's visual system (fonts/colors) for consistency.

### 7. About
- Brand story (Go Go Curry's origin, "Genki"/energy philosophy, gorilla mascot story).
- Good place to lean into bold branding — this can be the most visually expressive page alongside Home.
- Optional: team/founder note, franchise growth story teaser (linking to Franchising page).

### 8. Contact
- Simple inquiry/feedback form (Squarespace native Form block): Name, Email, Branch (dropdown: Times Square / Cambridge / General), Message/Feedback.
- Form submissions routed to Go Go Curry's inquiry email.
- Optional: general company contact info alongside the form.

## Mobile View Requirements
- All sections above need a mobile-specific layout pass:
  - Hero: stacked, shorter copy, single strong CTA visible without scrolling.
  - Times Square / Cambridge buttons: stack vertically, full-width tap targets.
  - Menu: single-column card layout.
  - Customer photo galleries: swipeable/scrollable strip instead of grid.
  - Footer: accordion or stacked sections for address/contact/socials.
- Confirm mobile preview in Squarespace's built-in mobile view before final publish.
